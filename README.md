An end-to-end Machine Learning pipeline designed to detect fraudulent credit card transactions using an optimized **Random Forest Classifier**. This framework handles highly skewed, imbalanced data distributions to minimize false negatives and guarantee reliable anomaly detection.

---

## 🎯 Key Metrics & Performance
* **High Predictive Accuracy:** The Random Forest architecture successfully classifies authentic vs. fraudulent transactions, achieving excellent trade-offs between precision and recall on unseen validation partitions.
* **Minimizing Financial Risk:** Specifically tuned to optimize the recall metric for the minority fraud class, ensuring that malicious transactions are captured without generating an overwhelming number of false alarms.
* **Robust Ensemble Structure:** Aggregates a multitude of independent decision trees to protect the overall pipeline against overfitting, variance traps, and outlier distortion.
